# OKB CRM v161 — Users Role Toolbar Alignment

هذه النسخة مبنية مباشرة على v160 وتحافظ على جميع مسارات الحسابات والصلاحيات والتقارير السابقة.

## التعديل

- تم تعديل تنسيق أعلى صفحة `👥 Users` فقط.
- أصبح شريط «اسم الـ Role الجديدة» وزر «＋ إضافة Role» ثم زرا `Refresh` و`Back` في صف واحد منظم على الشاشات الواسعة، وتظهر أزرار التنقل ناحية الشمال بجوار الشريط مباشرة.
- تم توحيد عرض وارتفاع زري `Refresh` و`Back` ومحاذاتهما رأسيًا مع شريط الـ Role.
- تمت إضافة استجابة آمنة للشاشات الصغيرة تمنع تداخل العناصر أو خروجها خارج الصفحة.
- رسالة حالة التحديث لا تغيّر موضع الأزرار أثناء تحميل البيانات.

## نطاق التغيير

- لا توجد تعديلات على JavaScript أو المحرك المالي أو الصلاحيات أو مسارات المستخدمين.
- لا توجد تعديلات على Supabase أو SQL أو أي Migration.
- جميع الملفات الأخرى مطابقة للنسخة v160.

- اختبارات الرجوع الخاصة بـ v159 وعددها 13: ناجحة.
