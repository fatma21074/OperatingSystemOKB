# OKB v156 — Audit Chat Focus

هذه النسخة مبنية مباشرة على **v155 Branch Rank Performance** وتحافظ على جميع وظائفها السابقة.

## التعديلات

- رسائل Chat التلقائية من **🛡️ Secretary Audit** أصبحت تُرسل فقط عند:
  - وجود خطأ فعلي.
  - تصحيح خطأ مسجل، مع عرض التعديلات التي تمت فقط.
- تنبيهات Secretary Audit العادية تظل مسجلة ومتاحة داخل صفحة المراجعة، لكنها لا تُرسل إلى Chat.
- رسائل **🛡️ Financial Audit** الخاصة بأخطاء التحصيل الفعلية مستمرة كما هي، ولا يتم إرسال تنبيهات عادية.
- تحسين تجميع التصحيحات بحيث تُقرأ كل المشكلات غير المحلولة للأوردر، وليس آخر مشكلة فقط، ثم تُرسل رسالة تصحيح واحدة بدون تكرار.
- فلتر الحالات في **🛡️ Secretary Audit** يبدأ دائمًا على **خطأ**، ويعود إلى **خطأ** أيضًا بعد Reset.
- تكبير اسم الفرع داخل الـFloating Sticky Badge أسفل صفحة الفرع مع الحفاظ على نفس الألوان والستايل.

## الأمان ونطاق التعديل

- لم يتم تغيير أي SQL أو Supabase migration.
- لم يتم تغيير المحرك المالي أو الخزنة أو Branch Rank أو الصلاحيات.
- الملفات البرمجية المعدلة فقط: `js/main.js` و`css/style.css` و`index.html`.
