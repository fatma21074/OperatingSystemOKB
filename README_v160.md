# OKB CRM v160 — Secretary Audit, Customer Profile, Treasury Links

هذه النسخة مبنية مباشرة على v159 وتحافظ على مسارات الحسابات والصلاحيات والتقارير السابقة.

## التعديلات

- في Secretary Audit، تظهر بجوار «محاولة حفظ مرفوضة» وصلة «فتح الأوردر» عندما يُحفظ أوردر صحيح لاحقًا لنفس العميل والفرع والمستخدم. الربط يستخدم بيانات الفترة المحمّلة بالفعل ولا يضيف استعلامًا جديدًا إلى تحميل الصفحة.
- فتح الأوردر من Secretary Audit يتم في New Tab عبر مسار الفتح الموحّد وفحص صلاحية الصفحة والفرع.
- Badge الخاص بـ Secretary Audit يحتسب أخطاء وتنبيهات وتصحيحات الفروع الأربعة فقط. طلب العدّ الدوري يتم كـ count داخل قاعدة البيانات، بينما أحداث OCR اللحظية تتحقق من فرع الأوردر قبل زيادة العداد.
- أوردرات شركات الشحن الخارجية لا تدخل صفحة Secretary Audit أو إشعارات الزر، حتى مع وجود اسم فرع قديم داخل السجل.
- زر «📝 إضافة ملاحظة» أصبح متاحًا داخل Customer Profile لكل المستخدمين، ويستهدف الأوردر الذي فُتح منه الملف. الملاحظة تحفظ اسم المستخدم والتاريخ والتوقيت وتلتزم بحماية أوردر Signed الحالية.
- تم تأمين إضافة الملاحظات بحيث تحافظ على Order Meta وCollect Meta (الخصم، العلامات، وسجل التحصيل) بدون تغيير.
- زر «فتح الأوردر» داخل Customer Profile يفتح الأوردر في New Tab مع إعادة فحص الصلاحيات.
- تعديل بيانات العميل يظل للأدمن فقط، ويقوم الآن بمزامنة الاسم والموبايلات والمنطقة والدكتور مع كل الأوردرات المرتبطة حتى تظهر التعديلات في Dashboard وصفحات الفروع. ملاحظات كل أوردر لا يتم استبدالها بملاحظات ملف العميل.
- في خزنة كل فرع تمت إضافة زر Ticket ID بجوار الطباعة. الزران يستخدمان نفس طابع أزرار خزنة الفروع المجمعة، وTicket ID يفتح الأوردر في New Tab.

## قاعدة البيانات

- لا يوجد SQL أو Migration جديد لهذه النسخة.
- جميع ملفات Supabase مطابقة للنسخة v159 byte-for-byte.
