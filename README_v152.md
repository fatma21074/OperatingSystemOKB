# OKB v152 — Pending للشهر الحالي

النسخة مبنية على Base v151. التعديل محصور في Pending Orders وعدّاده وتوضيح نطاقه في الواجهة والتصدير. يتقدم هذا الطلب على سلوك v151 الذي كان يعرض المتأخرات من جميع الشهور.

## السلوك الحالي

- تظهر أوردرات الشهر الحالي فقط، وفق تاريخ إنشاء الأوردر `created_at` وحدود الشهر بتوقيت القاهرة.
- يستمر شرط الحالة Delivering ومرور 3 أيام كاملة دون تحديث. طريقة احتساب آخر تحديث كما كانت.
- الأوردر المنشأ في شهر سابق لا يدخل ضمن Pending للشهر الحالي حتى لو تم تحديثه هذا الشهر.
- القيد يطبق في استعلام قاعدة البيانات نفسه وفي فلترة النتائج محليًا، فلا يتم تحميل متأخرات الشهور السابقة لهذه الصفحة.
- الشهر يتحدد تلقائيًا، بما فيه نهاية السنة وفبراير والشهور المختلفة. الصفحة المفتوحة تنتقل للشهر الجديد عبر دورة تحديث Pending الحالية (كل 45 ثانية)، وعند الفتح أو التحديث. استجابة طلب بدأ في شهر سابق لا تستبدل بيانات الشهر الجديد.
- عدّاد Pending يستخدم الشهر ونفس شروط التأخير والصلاحيات، ويكمل القراءة على دفعات حتى النهاية بدل سقف 2000 السابق.
- Export يتبع الفرع والبحث الحاليين داخل الشهر الحالي، دون إعادة حقلي «من / إلى». الأرقام المالية وتواريخ الإنشاء وآخر تحديث في أعمدة الملف محفوظة.
- قواعد الحذف والتحديث الحي، ومراجعة قائمة النتائج والصلاحيات قبل تنزيل الملف، وفتح الأوردر في New Tab محفوظة.

## ما تم الحفاظ عليه

لا يوجد تعديل على دوال الحساب المالي أو التحصيل أو قفل اليومية أو الصلاحيات أو تقرير Operation Manager أو Commission أو باقي الصفحات. ملف CSS وجميع ملفات Supabase لم تتغير. لا يلزم تشغيل أي SQL.

## التحقق

نجحت 9 مجموعات اختبارات محلية لدوال التطبيق الفعلية مع محاكاة Supabase وDOM وExcelJS. شملت:

- استبعاد أوردر الشهر السابق حتى لو كان آخر تحديث له في الشهر الحالي، وتطابق الفرع والبحث مع التصدير.
- حدود بداية ونهاية الشهر بتوقيت القاهرة، مع اختبار إضافي بتوقيت جهاز UTC.
- تطابق القائمة والعدّاد مع أكثر من 2000 أوردر، وحد 72 ساعة بدقة.
- صلاحيات الفروع وسحب الصلاحية أثناء التحميل، وفشل دفعة لاحقة دون تصدير نتيجة ناقصة.
- انتقال الصفحة المفتوحة للشهر الجديد، ورفض نتيجة طلب قديم، ونهاية السنة وفبراير الكبيس وغير الكبيس.
- منع تنزيل ملف قديم عند حذف أوردر أو تغير الشهر أثناء تجهيزه.
- مقارنة الكود أكدت أن كل المنطق خارج التعديلات المحددة لـPending مطابق لـv151. ملفات التنفيذ المتغيرة: `index.html` و`js/main.js` فقط؛ بقية الملفات السابقة وعددها 45 محفوظة دون تغيير. فحص JavaScript ومعرّفات HTML نجح.

الاختبارات محلية بالمحاكاة؛ لم يتم تشغيلها على قاعدة بيانات الإنتاج أو داخل متصفح فعلي أو باستخدام ExcelJS الحقيقي.
