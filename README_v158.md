# OKB v158 — Rescued Orders + True Branch Rank

هذه النسخة مبنية على v157 وتحافظ على كل التعديلات السابقة. نطاق التعديل محصور في `OKB Abnormal` ورقم `Rank` داخل `Branch Performance`.

## 1) أوردرات تم إنقاذها — OKB Abnormal

- الأوردر يُحسب ضمن **أوردرات تم إنقاذها** عندما تكون حالته الحالية `Signed` ويوجد في سجل حركته انتقال صريح سابق إلى إحدى الحالتين:
  - `Returned`
  - `Cancel`
- الرحلتان المعتمدتان هما بالتالي `Returned → Signed` و`Cancel → Signed`.
- الأوردر يُحسب مرة واحدة فقط حتى لو تكرر تسجيل الحالة في السجل.
- مجرد وجود كلمة `Returned` أو `Cancel` داخل السبب أو الملاحظات لا يكفي؛ يجب أن تكون قيمة حقل `الحالة:` الصريح في سجل الحركة.
- الفلتر الافتراضي عند فتح الصفحة أو الضغط على Reset يظل `Returned` كما كان.
- كارت وفلتر وشيت Excel أصبح اسمهم **أوردرات تم إنقاذها** ليشملوا المصدرين بوضوح.
- سجل تعديل الأوردر من صفحة الفرع أصبح يحفظ الحالة صراحةً، حتى يمكن التحقق من الرحلة بدون تخمين.

## 2) Rank الحقيقي للمستخدم المرتبط بفرع

- `Store Manager` و`Account Supervisor` والمستخدم الذي يفتح Branch Rank من صفحة فرع يرون رقم ترتيب الفرع الحقيقي بين الفروع الأربعة في عمود `Rank`.
- المستخدم يظل يرى بيانات الفروع المرتبطة بحسابه فقط.
- حساب الترتيب الكامل يتم داخل Supabase، وبعده تُرجع الدالة رقم فرع المستخدم فقط؛ لا يتم إرسال أوردرات أو مؤشرات باقي الفروع إلى المتصفح.
- Admin في صفحة Branch Rank العامة يظل يرى كل الفروع بالطريقة الحالية.
- الحساب يطابق محرك Branch Rank الحالي:
  - فترة التاريخ بتوقيت القاهرة.
  - أوردرات القيمة الصفرية أو الأقل من 40 مستبعدة.
  - استرجاع السعر التاريخي الصحيح من `ORDER_META` و`COLLECT_META` محفوظ.
  - `Group Cancel` مستبعد من `Total` ومن مقام نسبة التسليم.
  - Score = Conversion − (Return × 1.5).
- تحميل الرقم الحقيقي يعمل بالتوازي مع بيانات الفرع. فشل RPC لا يمنع فتح الصفحة ولا يعرض `1` بشكل مضلل؛ يظهر `—` مع رسالة إعادة المحاولة.

## خطوة Supabase المطلوبة مرة واحدة

شغّل الملف التالي كاملًا داخل Supabase SQL Editor:

`supabase/024_branch_rank_true_position.sql`

يعتمد الملف على Helpers الموجودة مسبقًا في:

`supabase/020_commission_role_enforcement.sql`

الملف الجديد لا يعدّل الأوردرات ولا يعيد كتابة أي بيانات. هو يضيف دالة قراءة آمنة لحساب الترتيب فقط.
