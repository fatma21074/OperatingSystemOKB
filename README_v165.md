# OKB v165 — Treasury Center + Refresh

تم بناء هذه النسخة على OKB v164 مع الحفاظ على كل التعديلات السابقة.

## التعديلات
- توسيط عنوان ومحتوى عمود `الإجراءات` في خزنة الفرع أفقيًا وعموديًا داخل الخلايا.
- توسيط عنوان ومحتوى عمود `🛡️ Financial Comment` أفقيًا وعموديًا داخل الخلايا.
- توسيط أزرار التحصيل وTicket ID والطباعة داخل عمود الإجراءات بدون تغيير وظائفها.
- إضافة زر `Refresh` في صفحة خزنة كل فرع بجوار زر Back.
- تحديث زر `Refresh` في صفحة خزنة الفروع المجمعة ليستخدم نفس `soft` style الموجود في `Shipping Rank Dashboard`.
- زر Refresh في خزنة كل فرع يستخدم نفس `soft` style والنص `Refresh` الخاص بـ Shipping Rank Dashboard.
- لا يوجد أي تغيير على Financial Engine أو Signed أو قفل اليومية أو الفلاتر أو المخزون أو صلاحيات الأزرار.

لا يحتاج هذا التعديل إلى SQL Migration جديد.
