# OKB v174 — Shipping Rank Export 3 Tabs

بُنيت النسخة على **v173** دون تغيير أي وظيفة أخرى.

## إصلاح Export في Shipping Rank
- تم إصلاح سبب فشل Export لبعض مستخدمي الفروع.
- الكود القديم كان يغير `branchShippingRankOverride` مؤقتًا أثناء التصدير، وهو ما يغير Scope Key الخاص ببيانات Shipping Rank ويجعل Snapshot التصدير فارغًا عند بعض المستخدمين رغم ظهور البيانات في الصفحة.
- التصدير الجديد يعتمد نفس الـSnapshot المحمّل والمصرح به للمستخدم، دون تغيير الـOverride أو الـScope.
- لا يمكن للتصدير توسيع نطاق البيانات خارج الفروع المسموح للمستخدم بها.

## ملف Excel الجديد — Branch Mode
يحتوي على 3 Tabs بنفس ترتيب الصفحة:
1. `تفاصيل الأداء الحالي`
2. `ترتيب الأداء`
3. `الأكثر تقليلًا للمرتجعات`

كل Tab يعكس نطاق الفروع المسموح به للمستخدم، ومع مستخدم الفرع يظهر فرعه فقط.

## Company Mode
تم الحفاظ على سلوك Export شركات الشحن القديم لتجنب أي Regression.

- لا يوجد SQL جديد.
- استبدل ملفات النسخة الحالية بملفات v174 فقط.
