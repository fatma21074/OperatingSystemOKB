# OKB v175 — Shipping Rank Export Clean Style

بُنيت النسخة على **v174** دون تغيير أي وظيفة أخرى.

## Shipping Rank Export
- تم الإبقاء على نفس ملف Excel ذي الثلاث Tabs:
  1. `تفاصيل الأداء الحالي`
  2. `ترتيب الأداء`
  3. `الأكثر تقليلًا للمرتجعات`
- تم إلغاء AutoFilter من التابات الثلاثة بالكامل.
- ألوان صف العنوان والهيدر أصبحت محصورة حتى آخر عمود فعلي يحتوي بيانات فقط، ولا تمتد بصريًا إلى بقية الشيت.
- لم يتغير Scope المستخدم أو صلاحيات المستخدم أو طريقة حساب بيانات Shipping Rank.

## التثبيت
- لا يوجد SQL جديد.
- استبدل ملفات النسخة الحالية بملفات v175 فقط.
