OKB Customer Profile CRM Update
================================

Database migration:
  supabase/001_customers_crm.sql

Included behavior:
- Click any customer name from Dashboard or Branch pages to open the customer profile.
- Glass-style customer profile with summary, order history and timelines.
- Open or print any historical order.
- Create a new order using the same customer data and a new Ticket ID.
- Admin-only customer data editing.
- Existing orders keep their original sales data.

Admin collection date update:
- Admin-only collection date field in the branch collection window.
- The selected date is saved in the collection history without changing the order creation date.
- Khazna and accounting reports use the selected collection date.
- Future dates and locked daily accounts are rejected.

Smart Export update:
- Dashboard and Branch Export buttons now offer Details and Smart Summary.
- Details preserves the original export behavior.
- Smart Summary exports an Overview sheet, one sheet per visible status,
  Doctor Performance, Employee Performance and Notes Review.
- All exported figures use the active page filters and date range.
