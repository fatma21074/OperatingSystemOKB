# OKB v157 — Store Manager Branch Rank

هذه النسخة مبنية مباشرة على v156 وتحافظ على جميع التعديلات السابقة.

## التعديل

- إظهار كارت `Branch Performance` لرول `Store Manager` داخل `Branch Rank`.
- إظهار التابات الثلاثة:
  - `تفاصيل الأداء الحالي`
  - `🏆 ترتيب الأداء`
  - `📉 الأكثر تقليلًا للمرتجعات`
- إظهار أعمدة التفاصيل الحالية: `Rank`, `Branch`, `Total`, `Signed`, `Delivering`, `Returned`, `Conversion`, `Return`.
- تفعيل مقارنة الشهر السابق اللازمة لتابَي الترتيب لهذا الرول.
- استمرار قفل النتائج وطلبات المقارنة على الفروع المرتبطة بحساب المستخدم فقط، بنفس مسار `Account Supervisor`.

## ملاحظات الأمان

- لا توجد تغييرات على Supabase أو المحرك المالي أو معادلات الأداء.
- لا توجد تغييرات على صلاحيات فتح `Branch Rank` نفسها؛ ما زالت خاضعة لصلاحية الرول.
- لم يتم تعديل أي صفحة أو زر آخر.
