# OKB v178 — Treasury Financial Audit Split

هذه النسخة مبنية مباشرة على v177 وتحافظ على جميع التعديلات السابقة.

## التعديلات

- فصل `🛡️ Financial Audit` الرئيسي في الهيدر عن `🛡️ Financial Audit` داخل الخزنة.
- الـ Financial Audit الرئيسي أصبح Admin-only ولا يعتمد على Permission الخزنة.
- إضافة Permission مستقلة داخل `🔐 Permission -> الخزنة — تقارير` باسم:
  - `🛡️ Financial Audit (خزنة)`
- زر Financial Audit في خزنة الفرع وخزنة الفروع يعتمد الصلاحية الجديدة فقط (والـAdmin متاح له دائمًا).
- Financial Audit (خزنة) يفتح على نفس تاريخ/فترة الخزنة المفتوحة.
- غير الـAdmin:
  - يرى فرعه فقط، ويتم حصر Query قاعدة البيانات على هذا الفرع.
  - لا يظهر له فلتر الموظفين.
  - لا يظهر له فلتر الفروع.
  - لا يستطيع تغيير تاريخ الـAudit بعيدًا عن تاريخ الخزنة التي فتح منها التقرير.
  - لا تظهر له Findings الخاصة بتحصيل/تصحيح تم بواسطة Admin، بما فيها تحذير تعدد سجلات التحصيل إذا كان مرتبطًا بحركة Admin.
- الـAdmin داخل Financial Audit (خزنة):
  - يحتفظ بكل الفلاتر.
  - يستطيع تغيير الفرع والتاريخ بعد فتح الصفحة.
  - يرى جميع النتائج كالمعتاد.
- Treasury Audit يراجع أوردرات `Signed` الخاصة بفترة الخزنة، بينما Financial Audit الرئيسي يحتفظ بمساره الأشمل السابق.
- Back navigation أصبح يحتفظ بنوع الـAudit (`main` أو `treasury`) عند الرجوع.
- فتح الأوردر من Treasury Audit للمستخدم غير Admin يظل مقيدًا بالفروع المسندة إليه.

## التثبيت

- لا يوجد SQL جديد.
- ارفع ملفات النسخة بدل النسخة السابقة.
- من صفحة Permission، فعّل `🛡️ Financial Audit (خزنة)` للـRoles المطلوبة.
