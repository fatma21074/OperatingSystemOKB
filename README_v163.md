# OKB v163 — Commission & Branch Khazna Layout

مبني مباشرة على Base: `OKB_v162_Unified_Filter_Center` مع الحفاظ على كل وظائف وتعديلات v162 السابقة.

## التعديلات

### Commission 🚩
- تجميع أزرار `Filter` و`Reset` و`Refresh` و`Back` في صف واحد متوازي كمجموعة واحدة.
- تصغير مساحة تاريخ المقارنة لتوفير مساحة للأزرار.
- تغيير عناوين تاريخ المقارنة من `مقارنة من / مقارنة إلى` إلى `من / إلى` فقط.
- الحفاظ على `مقارنة تلقائية` والـlogic الحالي للمقارنة بدون تغيير.
- زر `Back` يستخدم نفس `goBackToPreviousPage()` ونظام التنقل الموحد الموجود في باقي الصفحات.

### خزنة الفرع
- إزالة زر `↻ Refresh` من رأس صفحة الخزنة.
- إزالة زر الرجوع القديم `← رجوع للفرع` واستبداله بزر `Back` الموحد الخاص بالنظام.
- زر `Back` يحافظ على نفس شروط وسلوك الرجوع للصفحة السابقة.
- تحريك/فصل عمود `الإجراءات` بصريًا ناحية الشمال بمسافة بسيطة، لإبعاد أزرار `Ticket ID` و`طباعة` عن عمودي التاريخ والحالة.

## ملاحظات أمان
- لا يوجد أي تعديل على Signed أو المخزون أو الحسابات أو Commission formulas أو المحرك المالي.
- لا توجد Migration جديدة لـ Supabase في هذا الإصدار.
