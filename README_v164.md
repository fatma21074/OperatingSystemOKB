# OKB v164 — Khazna Financial Comment

تم بناء هذه النسخة على OKB v163 مع الحفاظ على كل التعديلات السابقة.

## التعديلات
- إعادة عمود الإجراءات في خزنة الفرع إلى التدفق الطبيعي للجدول وإلغاء المسافة التي كانت تفصل الهيدر بصريًا.
- إضافة عمود جديد في أقصى الشمال باسم `🛡️ Financial Comment`.
- نقل ملاحظات المحرك المالي لكل أوردر إلى العمود الجديد بدل عرضها داخل الإجراءات.
- الإبقاء على منطق Financial Audit كما هو دون تغيير الحسابات أو القفل المالي.
- إزالة شارة `🔒 مقفول` من جوار كل أوردر بعد قفل اليومية؛ القفل نفسه وصلاحياته ما زالت تعمل كما كانت.
- الحفاظ على Ticket ID والطباعة والتحصيل داخل عمود الإجراءات.
- تحديث العرض على الموبايل لاحتواء العمود الجديد دون كسر Card layout.

لا يحتاج هذا التعديل إلى SQL Migration جديد.
